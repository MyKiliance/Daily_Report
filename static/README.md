# daily-report — รายงานการก่อสร้างประจำวัน

เว็บแอป Flask สำหรับกรอกแบบฟอร์มรายงานการก่อสร้างประจำวัน (โครงการปรับปรุงห้องเรียน 2507, 2509, 2510 ม.อ. ภูเก็ต) โดย:

- กรอกข้อมูลผ่านหน้าเว็บแบบมีกรอบ/เส้นแบ่งชัดเจนในแต่ละหมวด แล้ว **บันทึกลง SQLite** (`report.db`, สร้างอัตโนมัติ)
- **ดูตัวอย่าง PDF ในหน้าเว็บได้ทันที** ก่อนบันทึกหรือดาวน์โหลด โดยใช้ pdf.js render เอกสารสดๆ จากข้อมูลในฟอร์ม
- ดูประวัติรายงานที่บันทึกไว้ทั้งหมด, โหลดกลับมาแก้ไข, หรือลบได้
- ส่งออกแต่ละรายงานเป็นไฟล์ PDF ที่จัดหน้าแบบมีกรอบ/เส้นแบ่งเหมือนกับหน้าเว็บ

## โครงสร้างไฟล์

```
daily-report/
│
├── app.py                  Flask backend (routes, SQLite, สร้าง PDF, พรีวิว)
├── requirements.txt
├── report.db                สร้างอัตโนมัติเมื่อรันครั้งแรก (ไม่ต้องสร้างเอง)
├── template.pdf              เอกสารต้นฉบับ (ไว้อ้างอิงรูปแบบ)
│
├── templates/
│   └── index.html            หน้าแบบฟอร์ม + ปุ่มพรีวิว + ตารางประวัติ
│
├── static/
│   ├── style.css
│   ├── script.js              เรียก API, จัดการพรีวิวด้วย pdf.js
│   ├── pdf.min.js             ไลบรารี pdf.js (มากับโปรเจกต์)
│   └── worker.min.js          pdf.js worker
│
├── output/
│   └── preview.pdf            ไฟล์ล่าสุดที่ถูกสร้างจากการกด "ดูตัวอย่าง PDF" (เขียนทับทุกครั้ง)
│
└── fonts/
    ├── Sarabun.ttf             ฟอนต์ไทยสำรองที่แถมมาให้ (Google Fonts, OFL license)
    ├── Sarabun-Bold.ttf
    └── (ใส่ THSarabunNew.ttf / THSarabunNew-Bold.ttf เองได้ ถ้ามี — โปรแกรมจะเลือกใช้ไฟล์นี้ก่อนอัตโนมัติ)
```

> **หมายเหตุเรื่องฟอนต์:** ฟอนต์ "TH Sarabun New" ตัวจริงเป็นฟอนต์ลิขสิทธิ์ที่ไม่สามารถแนบมาในโปรเจกต์นี้ได้โดยตรง
> ถ้าคุณมีไฟล์ `THSarabunNew.ttf` และ `THSarabunNew-Bold.ttf` อยู่แล้ว ให้วางไว้ในโฟลเดอร์ `fonts/`
> โปรแกรมจะตรวจสอบและใช้ไฟล์นั้นแทนฟอนต์ Sarabun สำรองโดยอัตโนมัติ (ไม่ต้องแก้โค้ด)

## วิธีติดตั้งและรัน

```bash
cd daily-report
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:5000`

## การใช้งาน

1. กรอกข้อมูลในแบบฟอร์ม
2. กด **"ดูตัวอย่าง PDF"** เพื่อดูหน้าเอกสารที่จะได้ ก่อนบันทึกหรือดาวน์โหลดจริง (จะเปิดเป็นหน้าต่างพรีวิวในเว็บ ไม่ต้องออกจากหน้า)
   - ในหน้าต่างพรีวิว กด **"ดาวน์โหลด"** เพื่อเก็บไฟล์ PDF ที่กำลังดูอยู่ได้ทันที
3. กด **"บันทึกข้อมูล"** เพื่อบันทึกรายงานลงฐานข้อมูล
4. กด **"ดูรายงานที่บันทึกไว้"** เพื่อดูประวัติรายงานทั้งหมด และ **ดูข้อมูล / ดาวน์โหลด PDF / ลบ** รายงานแต่ละรายการ

## หมายเหตุ

- `report.db` และไฟล์ `output/preview.pdf` จะถูกสร้าง/เขียนทับอัตโนมัติ ไม่ต้องสร้างเอง
- การจัดวางใน PDF เป็นการ "จำลอง" รูปแบบของ `template.pdf` ต้นฉบับด้วย reportlab ใหม่ทั้งหมด (ไม่ใช่การกรอกทับไฟล์ PDF เดิม)
