# daily-report — รายงานการก่อสร้างประจำวัน

เว็บแอป Flask สำหรับกรอกแบบฟอร์มรายงานการก่อสร้างประจำวัน โดยหน้าเว็บและไฟล์ PDF ที่สร้างออกมา
**มีโครงสร้าง/ตาราง/หัวข้อ ตรงกับไฟล์ต้นฉบับ `template.pdf` ทุกจุด** (ขนาดหน้ากระดาษ Letter 612×792pt
เท่าต้นฉบับ, ตำแหน่งตาราง 3 ตารางตรงตามต้นฉบับ) และทุกช่องข้อมูลแก้ไขได้ทั้งหมด

## โครงสร้างเอกสาร (ตรงกับ template.pdf)

1. **หัวเอกสาร** (ไม่มีกรอบ เหมือนต้นฉบับ) — ชื่อรายงาน, โครงการ, สถานที่, เลขที่สัญญา (แก้ไขได้ทั้งหมด)
2. **จำนวนวันทำงาน / เหลือ** และ **วันที่ (วัน/เดือน/พ.ศ. แยก 3 ช่อง)**
3. **สภาพอากาศ** เช้า/บ่าย (แจ่มใส / ฝนตก / ฝนตกหนัก)
4. **จำนวนรวม** เจ้าหน้าที่ผู้รับจ้าง และเครื่องจักรผู้รับจ้าง
5. **ตารางที่ 1** — จำนวนเจ้าหน้าที่/เครื่องจักร: ตาราง 3 คู่คอลัมน์ (ประเภท/คน) × 7 แถว ตรงตามต้นฉบับ
   (เจ้าหน้าที่สำนักงาน, นายช่างคุมงาน, ช่างไม้, ช่างเหล็ก, ช่างปูน, กรรมกร, ช่างทาสี | รถขุด, รถหกล้อ,
   Mobile Crane, อื่นๆ | ช่างโครงหลังคาเหล็ก, ช่างไฟฟ้า)
6. **ตารางที่ 2** — รายละเอียดงาน: 3 คอลัมน์ (งานที่ดำเนินการ / ตำแหน่งที่ดำเนินการ / ปริมาณงานที่ทำได้)
7. **ตารางที่ 3** — ปัญหา/อุปสรรค และแนวทางแก้ไข (2 คอลัมน์)
8. **ลายเซ็น** ผู้ควบคุมงาน และ ผู้รับจ้าง/ตัวแทนผู้รับจ้าง
9. **หมายเหตุ** กำหนดส่งมอบ

ทุกช่อง (รวมถึงป้ายหัวเอกสาร, วันที่, จำนวนคน, รายละเอียดงาน ฯลฯ) เป็นช่องกรอกที่แก้ไขได้ทั้งหมด
ทั้งในหน้าเว็บและจะถูกนำไปวาดใน PDF ที่ตำแหน่งเดียวกับต้นฉบับ

## ฟีเจอร์

- กรอกข้อมูลผ่านหน้าเว็บ แล้ว **บันทึกลง SQLite** (`report.db`, สร้างอัตโนมัติ)
- **พรีวิว PDF อัปเดตอัตโนมัติ** ทางฝั่งขวาของหน้าจอทุกครั้งที่พิมพ์/แก้ไขข้อมูล (มี debounce กันยิงถี่)
- ดูประวัติรายงานที่บันทึกไว้ทั้งหมด, โหลดกลับมาแก้ไข, หรือลบได้
- ส่งออกแต่ละรายงานเป็นไฟล์ PDF ที่จัดหน้าตรงกับ `template.pdf` ต้นฉบับ

## โครงสร้างไฟล์

```
daily-report/
│
├── app.py                  Flask backend + ฟังก์ชันวาด PDF ให้ตรงกับ template.pdf
├── requirements.txt
├── report.db                 สร้างอัตโนมัติเมื่อรันครั้งแรก
├── template.pdf               เอกสารต้นฉบับ (ใช้อ้างอิงเปรียบเทียบ)
│
├── templates/
│   └── index.html             ฟอร์มกรอกข้อมูล (ตรงตามโครงสร้าง template.pdf)
│
├── static/
│   ├── style.css
│   ├── script.js
│   ├── pdf.min.js
│   └── worker.min.js
│
├── output/
│   └── preview.pdf            ไฟล์ล่าสุดจากการพรีวิว (เขียนทับทุกครั้ง)
│
└── fonts/
    ├── Sarabun.ttf             ฟอนต์ไทยสำรอง (ใช้ได้จริง ทดสอบแล้ว)
    ├── Sarabun-Bold.ttf
    └── (ใส่ THSarabunNew.ttf / THSarabunNew-Bold.ttf เองได้ถ้ามี — ใช้แทนอัตโนมัติ)
```

## วิธีติดตั้งและรัน

```bash
cd daily-report
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:5000`

## หมายเหตุ

- ถ้าเคยมี `report.db` จากเวอร์ชันก่อนหน้า (ที่โครงสร้างฟิลด์ต่างจากนี้) ให้ลบไฟล์นั้นทิ้งก่อนรันเวอร์ชันนี้
  เพราะโครงสร้างฟิลด์เปลี่ยนไปให้ตรงกับ template.pdf (เช่น แยกวันที่เป็นวัน/เดือน/ปี)
- `output/preview.pdf` จะถูกเขียนทับอัตโนมัติทุกครั้งที่มีการพรีวิว ไม่ต้องสร้างเอง
